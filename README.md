Lucia's walk out of prison from GTA VI Trailer 2 — watchtower, release counter, the gate walk-out and the reunion — cut into a 24.3 s vertical Short with a make.fun pitch end card. This repository hands in the video's YouTube address; main.ts copies VIDEO.json to /output for the grader.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
